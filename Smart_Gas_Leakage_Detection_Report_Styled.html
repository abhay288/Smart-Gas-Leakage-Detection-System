Abstract

The Smart Gas Leakage Detection and Alert System is an IoT-based solution that continuously monitors combustible gases using an MQ2 Gas Sensor and ESP32. The system classifies gas concentration into Safe, Warning, and Danger levels using LEDs and an active buzzer. Sensor readings are transmitted over Wi-Fi to the Blynk IoT platform for live monitoring and notifications, making it suitable for homes, laboratories, restaurants, and industrial environments.

Objectives

  • Detect combustible gas leakage in real time.
  • Provide visual and audible alerts.
  • Enable remote monitoring using Blynk IoT.
  • Improve public and industrial safety.

Working Principle

  1. ESP32 connects to Wi-Fi and the Blynk cloud.
  2. MQ2 sensor continuously measures gas concentration.
  3. ESP32 compares readings with predefined thresholds.
  4. Safe Green LED ON.
  5. Warning Green + Yellow LEDs ON.
  6. Danger Red LED and buzzer activate, and a Blynk notification is sent.
