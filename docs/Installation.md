# Installation Guide

1. Clone this repository.

2. Open `Smart_Gas_Detector.ino` in Arduino IDE.

3. Install the required libraries:

   * Blynk
   * WiFi (ESP32)

4. Update the following values in the code:

   * WiFi SSID
   * WiFi Password
   * Blynk Template ID
   * Blynk Auth Token

5. Select **ESP32 Dev Module**.

6. Select the correct COM Port.

7. Upload the code.

8. Open Serial Monitor at **115200 baud**.

9. Open the Blynk application to monitor the gas sensor in real time.
